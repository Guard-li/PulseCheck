## 现场人工验收

- [ ] 在目标 Windows 11 专业版 x64 机器安装服务
- [ ] 重启 Windows，确认服务自动恢复
- [ ] 非管理员便携运行，确认进入受限模式
- [ ] 管理员服务运行，确认 SMART/安全数据可读情况
- [ ] 中文用户名和中文路径
- [ ] Intel 核显 + NVIDIA 独显
- [ ] NVMe + SATA HDD
- [ ] Wi-Fi、以太网、手机热点、USB 网络共享
- [ ] 多网卡和网络切换
- [ ] 睡眠/唤醒、断网/恢复
- [ ] 1,000 次实时数据推送无异常
- [ ] 连续运行 7 天内存和句柄趋势
- [ ] 报告目录无权限、数据库损坏、磁盘空间不足
- [ ] Windows Service 安装、升级、卸载和保留数据
- [ ] Android 真机二维码/手动 IP 配对
- [ ] 平板横屏和深色模式

## 通过标准

- 采集值与 Windows 系统工具/厂商工具交叉核对一致。
- 所有不可用指标有明确原因。
- 无管理员权限时无崩溃。
- 报告中的每个扣分项能追溯到规则 ID 和证据字段。
- 敏感 API 无 Token 均返回 401。
- 默认不会自动公网上传或修改系统安全设置。
